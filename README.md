# Projets de Captain-VII

Le site https://captain-vii.github.io : la liste de mes petits projets vibe codés, prêts à télécharger.

La page lit automatiquement mes dépôts et leurs dernières versions (releases) sur GitHub :
un nouveau dépôt ou une nouvelle version apparaît sur le site sans rien modifier ici.

Pour changer un nom affiché ou cacher un dépôt, voir `TITLES` et `HIDDEN` en haut du script dans `index.html`.
